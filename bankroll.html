Η ΦόρμουλαThe Formula

P = stake × (odds − 1)  // κερδισμένοwin
P = − stake  // χαμένοloss
P = 0  // push
Units Played = Σ stake
Bankroll = Start + Σ P
Yield % = Σ P ÷ Units Played × 100
Drawdown = peak − current
